===============================================================================
                     PRISM - HOW EACH DERIVED KPI IS CALCULATED
===============================================================================
  Labels:  OBSERVED = straight from the data   DERIVED = fixed formula
           ESTIMATED = depends on an editable assumption
  Figures: current dataset, 75,618 Lazada PH Fabric Care reviews.


-------------------------------------------------------------------------------
 1. BUILDING BLOCKS (per review, at import)
-------------------------------------------------------------------------------

 Sentiment     Lexicon method (VADER-style) for English, Filipino, Taglish.
               Word scores -4..+4, adjusted for negation (x -0.74),
               intensifiers, "but/pero" and "!".
                 compound = sum / sqrt(sum^2 + 15)        range -1..+1
                 >= +0.05 positive | <= -0.05 negative | else neutral
               Star ratings are not used. No text = no sentiment.

 Themes        Keyword rules, each theme in one of the 5 Vectors.
               Theme sentiment = negative if negative mentions >= positive
               ones, positive if any positive, else neutral.

 Trust weight  verified (1.0 / unknown 0.8 / no 0.6)
               x text (normal 1.0 / 1-3 chars 0.7 / none 0.5)
               x (1 + min(0.5, 0.1 x log2(1 + helpful votes)))
               Duplicates = 0.

 Conflict      4-5 stars with compound <= -0.30, or
               1-2 stars with compound >= +0.30.


-------------------------------------------------------------------------------
 2. OVERVIEW KPIs
-------------------------------------------------------------------------------

 Sentiment share                                                     DERIVED
   label count / reviews with a sentiment label (reviews with text)
   e.g. 1,730 / 55,989 = 3.1 % negative

 Intelligence Score (0-100)                                          DERIVED
   S = (avg compound + 1) / 2            sentiment, 0-1
   R = (avg stars - 1) / 4               rating, 0-1
   Q = 1 - share with a negative theme   issue-free, 0-1
   (averages are trust-weighted; a missing part is dropped, weights rescaled)
     raw   = 100 x (0.40 S + 0.35 R + 0.25 Q)
     score = (w x raw + 20 x prior) / (w + 20)
   w = sum of trust weights; prior = raw score of the whole view.
   Shrinkage applies to products/brands/retailers; the tile shows raw.
   e.g. raw 60, w 10, prior 89.5 -> (600 + 1,790) / 30 = 79.7

 Products                                                            DERIVED
   Distinct canonical products. Listings matched by UPC, then brand +
   retailer code, then brand + name + size, then >= 85 % name similarity.

 Rating disagrees with text                                          DERIVED
   Count of conflict-flagged reviews. Current: 882

 Data quality (0-100, whole import, ignores filters)                 DERIVED
   100 x (1 - 0.35 no text - 0.20 duplicates - 0.20 bad/missing dates
            - 0.15 bad/missing ratings - 0.10 no verified flag)   [shares]
   e.g. 9.0 + 0 + 0.5 + 0.4 + 0.3 = 10.2 lost -> 89.8

 Analyst hours saved                                               ESTIMATED
   reviews x minutes per review / 60 - processing hours
   Minutes per review = 1.5 (editable assumption).
   e.g. 75,618 x 1.5 / 60 - 0.003 = ~1,890 h


-------------------------------------------------------------------------------
 3. PERSONA KPIs   (defaults: R&D = Product + Packaging, Sales = Retail Exec.)
-------------------------------------------------------------------------------

 Claims, ads and labels (Marketing)                                  DERIVED
   Reviews with a Communication theme. Current: 1,426

 Leaks, caps and seals (R&D)                                         DERIVED
   Negative mentions of Leaks and spills + Cap and seal + Packaging
   condition. Current: 977

 Products below average (R&D)                                        DERIVED
   Products with 30+ reviews whose score < the view's prior.
   Current: 116 of 272

 Rising complaint themes (R&D, and attention lists)                  DERIVED
   Negative-mention share, last 30 days vs the 90 days before (ending at
   the latest review date). Two-proportion z-test:
     z = (p1 - p0) / sqrt(p(1 - p)(1/n1 + 1/n0)),  p = pooled share
   Rising if z >= 1.96 and both windows have 30+ reviews.

 Retail Execution negative share (Sales)                             DERIVED
   Reviews with a negative RE theme / reviews with any RE theme.
   Uses theme sentiment, not review sentiment. Current: 7.8 %

 Delivery and seller issues (Sales)                                  DERIVED
   Negative mentions of Delivery speed + Seller and courier service +
   Wrong or missing item. Current: 864

 Authenticity and expiry (Sales)                                     DERIVED
   All mentions of Authenticity + Expiry and freshness. Current: 1,725

 Untagged reviews (Analyst)                                          DERIVED
   Reviews with text but no theme. Current: 7,983

 Reviews verified (Analyst)                                         OBSERVED
   Reviews checked in the Verify queue. Target 385 = sample for
   +/- 5 % accuracy at 95 %: 1.96^2 x 0.25 / 0.05^2. Current: 0

 Theme coverage by vector (Analyst)                                  DERIVED
   Reviews with a theme in the vector / reviews with text.
   Coverage is not accuracy.


-------------------------------------------------------------------------------
 4. GENERAL RULES
-------------------------------------------------------------------------------
 - All KPIs follow the filters except data quality and processing time.
 - Duplicates are excluded. Reviews without text count for ratings only.
 - "Mentions" KPIs can count one review more than once; "reviews" cannot.
 - OBSERVED, no formula: Reviews, Average rating, Verified purchases,
   Processing time.
